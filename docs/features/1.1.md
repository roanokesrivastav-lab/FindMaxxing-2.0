# 1.1 Design tokens and primitives

Built 2026-11-05 under [beta-build-rules.md](../beta-build-rules.md). Ticket: roadmap-80.md §4, M1 "1.1"
(rewritten to match founder-decisions.md: two treatments, role-based surfaces, photography-led, no
DateBlock).

## Contract

- **Objective:** tokens and primitives that every later UI ticket points at: three type roles, a
  spacing scale with one left edge, role-based surfaces, the two treatments, and the primitives `Row`,
  `SectionHeader`, `Surface`, `StatusLabel` and `PlaceGlyph`. No DateBlock. A demo-only `/dev/ui` page
  shows each with long text, no photo and 200% text.
- **Out of scope:** restyling existing screens ("do not restyle existing screens yet beyond what
  breaks"); migrations; dependencies.

## Choices recorded (owner can't be asked during a run; recommended option taken)

- **The legacy `.card` stays.** The ticket says both "remove the default card" and "do not restyle
  existing screens". Deleting `.card` would restyle 55 files. It is kept, marked legacy in `globals.css`
  for existing screens only, and new UI uses role surfaces. Each screen drops `.card` in its own ticket
  (1.5, 2.5, 4.1, …).
- **Type role sizes** use `clamp()` across each range (28–32, 16–18, 14–16px), all in `rem`, so a 200%
  browser text setting scales them.
- **Treatments** are CSS scopes (`.treatment-editorial`, `.treatment-utility`) that set section and row
  rhythm. Their full visual identity is defined as screens adopt them (1.5 utility, 4.1 editorial).
- **`/dev/ui` is gated twice:** demo mode **and** the `pilotFoundation` flag (`src/lib/devUi.ts`). It
  404s on any Supabase deployment, and wherever pilot flags are off.
- **The 200% view** is `/dev/ui?text=200`, which sets the root font size to 200%: the same effect as a
  200% browser text setting on rem-based styles.
- **The demo photo** is a generated inline SVG, because the app ships no stock photos and an external
  image would be a real network request.

## Changes

- `src/app/globals.css`:
  - Type tokens `--text-page-title` (28–32px, Bricolage), `--text-item-title` (16–18px, Figtree) and
    `--text-body` (14–16px, Figtree), with `.type-page-title`, `.type-item-title` and `.type-body`.
  - Spacing tokens `--spacing-hair` 4, `--spacing-item` 8, `--spacing-row` 16, `--spacing-section`
    24–32 and `--spacing-edge` 16 (Tailwind utilities such as `gap-row`, `mt-section`, `px-edge`).
  - Surfaces `.surface-raised` (the only shadow), `.surface-flat` (no box, hairline between rows) and
    `.surface-inset` (tinted, no border or shadow).
  - Treatments `.treatment-editorial` and `.treatment-utility`. `.card` kept, marked legacy.
  - Warm paper palette and both fonts unchanged.
- `src/components/ui/`:
  - `Surface.tsx`: `variant` of raised, flat or inset, with a polymorphic `as`.
  - `Row.tsx`: title, meta, trailing slot, optional media and link. A photo leads when present;
    otherwise `PlaceGlyph`. Titles wrap and clamp at two lines. The row wraps at large text sizes.
  - `SectionHeader.tsx`: a real heading on the left edge, section gap above, wrapping action.
  - `StatusLabel.tsx`: five tones, each with its own icon shape plus visible text, never colour alone.
  - `PlaceGlyph.tsx`: category tile, decorative unless labelled; unknown categories fall back to "other".
- `src/app/dev/ui/page.tsx` and `src/lib/devUi.ts`: the demo-only primitives page.
- `tests/ui-primitives.test.ts` (new, 12 tests).

Migrations: none. Dependencies: none. Existing screens: unchanged.

## Test results

- `tests/ui-primitives.test.ts`: 12/12. Covers:
  - type-role pixel ranges parsed from `globals.css`, and the fonts per role;
  - the spacing scale, shadow only on raised, the inset tint;
  - palette and fonts kept; no `DateBlock` anywhere in `src/components/ui`;
  - each primitive rendered on the server: photo vs glyph, long text, wrapping row, five distinct
    status shapes, glyph labelling and fallback, heading semantics;
  - `/dev/ui` rendering every primitive, the 200% view, no external `src`/`href`, and a 404 outside
    demo + `pilotFoundation` (including when only `all` is set, and in Supabase mode).
- **Real browser, production demo build, 390×844** (scratch script, not committed): `/dev/ui` normal and
  `?text=200` both returned 200, with **0 px horizontal overflow**, **no page errors** and **axe: 0
  violations** (target-size enabled). The root font went 16→32px and the page title 28.7→56px.
  - The first browser run found two real defects, both fixed before this commit: a nested `<main>`
    (axe landmark violations), and at 200% `Row` squeezed the title to a few characters with mid-word
    breaks. Rows now wrap, and the screenshots were re-checked.
- `npm run check` with `TEST_DATABASE_URL` set (local PostgreSQL 16): **exit 0**. Typecheck, lint,
  **68 files / 1,100 tests passed, none skipped**, Turbopack build OK (`/dev/ui` in the route list).
- Not re-run for this ticket: `npm run e2e` and `npm run a11y` (no existing screen changed; 0.3's e2e
  run was 19/19).

- `PlaceGlyph` and row media sizes are in px (56): they stay fixed at 200% text while the text scales.
  That is intended for icons, but recorded.
