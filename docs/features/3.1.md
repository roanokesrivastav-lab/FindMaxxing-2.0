# 3.1 Richer saves

Built 2026-11-05, lane B2. Ticket: roadmap-80.md §4 M3 "3.1" (Mapstr decision: save first, tags later; what vs why;
who recommended it). Flag: `pilotLibrary`. Migration: `0062_save_details.sql`.

## Contract

- **Objective:** saving stays one tap and asks nothing. Saved places gain a private note, personal tags, a source URL,
  `recommended_by` (free text) and a status want_to_go / visited. All owner-only, with "Only you" next to each private
  field. Tags are suggested afterwards and never required. What the place is (community info) stays apart from why you
  saved it, on the place page and in the library.
- **Out of scope:** the library tools themselves (3.2 shows the details in `/saved` and edits them in bulk), imports.
- **Required tests:** another user, anon, moderator, share metadata and recommendations never see the fields; outing
  members (future, M5) are covered structurally (no function or view reads the columns); saving with no tags works;
  dismissing a suggestion changes nothing.

## Choices recorded (recommended option taken)

- **Tag-suggestion source:** the viewer's own most-used personal tags first, then the place's community interest tags
  (contributor-chosen, shown by label). Nothing generated, nothing about the place invented. Up to six. "Not now" hides
  them in the browser only; nothing is stored, so dismissing changes nothing.
- **Details are columns on `saved_places`**, so they live and die with the save (unsave removes them, as Mapstr does). The
  owner gets an UPDATE policy and column grants on just those five columns; identity and date are fixed by trigger.
- **Limits:** note ≤ 500, ≤ 10 tags of 1–24 characters (lowercased, deduplicated in the database trigger too), source URL
  must be http(s) ≤ 500, recommended_by ≤ 80.
- **Where it shows:** on the 2.5 place page (`pilotExplore`), a "Why you saved it" section right after the You block,
  before Friends and Community, rendered on the server only for the owner. With `pilotLibrary` off nothing is shown and
  nothing else changes. The legacy place page (pilotExplore off) does not get it.
- **Demo:** optional fields on the existing `savedPlaces` rows; old rows read as want to go with no details.
